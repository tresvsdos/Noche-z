# Noche Z · Puerto Venecia

Mapa 3D de Puerto Venecia (Zaragoza) para la noche zombi del 31 de octubre de 2026,
con ubicación del equipo en directo y walkie-talkie.

Ábrelo en el navegador del móvil (Chrome o Safari), pulsa **Equipo**, pon tu nombre y comparte el enlace
con tu grupo. Mantén la página abierta y la pantalla encendida durante el juego.

puntos del evento tomados del mapa impreso de Love Zombies.
