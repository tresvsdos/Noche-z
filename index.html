Equipo en directo

La ubicación en directo y el walkie-talkie necesitan el GPS y el micrófono del móvil, y el visor de Claude no deja usarlos.

Abre la versión de equipo en el navegador (Chrome o Safari):

¿Quién eres? Toca tu nombre para entrar

Tu ubicación solo la ve quien tenga el enlace del equipo, y solo mientras tengas esta página abierta. Todo viaja cifrado de extremo a extremo.

    Pantalla negra que casi no gasta: sigues enviando la ubicación y oyendo el walkie. Si sales de la web o bloqueas el móvil, el equipo deja de verte.

    Ubicación—
    Micrófono—

    Estás abriendo el enlace dentro de otra app. Ábrelo en Safari o Chrome: toca los tres puntos o el botón de compartir y elige «Abrir en el navegador».

    Si pone «Bloqueado», el móvil no volverá a preguntar: hay que cambiarlo en los ajustes.

    iPhone · Safari
    1. Ajustes → Privacidad y seguridad → Localización: activada.
    2. En esa pantalla baja a Sitios web de Safari → Al usar la app y activa Ubicación exacta.
    3. Ajustes → Apps → Safari (en iOS 17: Ajustes → Safari) → Ubicación y Micrófono → Preguntar o Permitir.
    4. En Safari, con esta página abierta, toca aA en la barra de direcciones → Ajustes del sitio web → Ubicación y Micrófono: Permitir.
    5. Si no oyes el walkie, sube el volumen y quita el modo silencio.
    iPhone · Chrome
    1. Ajustes → Privacidad y seguridad → Localización: activada.
    2. Ajustes → Apps → Chrome → Ubicación: Al usar la app con Ubicación exacta, y Micrófono activado.
    3. Vuelve a Chrome y recarga la página.
    Android · Chrome
    1. Activa la Ubicación del móvil (desliza desde arriba).
    2. En Chrome toca el icono a la izquierda de la dirección → Permisos → Ubicación y Micrófono: Permitir.
    3. Si sigue sin ir: Ajustes → Aplicaciones → Chrome → Permisos → Ubicación Permitir solo mientras se usa y Micrófono permitido.

      Cómo moverte

      • Un dedo arrastra el mapa
      • Pellizca para acercar o alejar
      • Gira dos dedos para rotar
      • Dos dedos arriba o abajo para inclinar
      • Doble toque acerca · un toque marca la celda
      • Arrastra con el botón izquierdo para moverte
      • Rueda para acercar hacia el cursor
      • Botón derecho (o Mayús + arrastrar) para girar e inclinar
      • Doble clic acerca · clic marca la celda · teclas ← → ↑ ↓, + −, Q E
